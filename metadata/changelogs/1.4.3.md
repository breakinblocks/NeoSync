# NeoSync 1.4.3

Picking a shell away from a shell storage no longer looks like an ordinary death. The death screen stays out of the way and you are carried straight into the shell you picked instead of being asked to respawn first. Your body still drops what it was carrying where it fell, so grave mods keep working exactly as before.

Choosing a shell while you are already dead now takes you there right away as well, rather than waiting for you to click respawn.

If a sync cannot finish, because the shell was broken or the storage is gone, you are put back where you were with the death screen returned to you, so there is always a way out.

Faulty pack scripts listening for sync events can no longer disconnect players. Errors are written to the server log instead.
