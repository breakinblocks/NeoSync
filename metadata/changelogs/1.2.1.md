# NeoSync 1.2.1

Fixes the server freeze reported in issue [#2](https://github.com/breakinblocks/NeoSync/issues/2).

## Fixes

- **Syncing no longer freezes the server.** Finding your shell container during a sync could force an unloaded chunk to generate on the spot, which wedged the server thread — after the 10-second sync timer ran out you'd get your movement back, but blocks stopped responding. Shell-container lookups now skip positions whose chunk isn't already loaded instead of forcing generation.
