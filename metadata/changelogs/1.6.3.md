# NeoSync 1.6.3

Switching bodies while inside a Shell Storage or Shell Constructor that is part of a physics object no longer kills you. The block was not being found, so the game treated it as a remote sync and killed the body you were leaving behind instead of storing it.

Shells kept in a block on a physics object are now tracked from the block itself, so syncing back into one works even when the object has turned or the shell was grown in a Constructor.
