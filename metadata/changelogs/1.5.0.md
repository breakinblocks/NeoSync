# NeoSync 1.5.0

You can name your shells now. Open the shell menu, right click the shell you want to name, type a name and press Enter. Escape backs out without changing anything, and clearing the box puts the coordinates back.

Every slice of the menu shows its shell's name, so a wall of storages reads as Home, Mining Base and Nether Camp instead of a wall of numbers. Shells you have not named still show where they are, exactly as before.

Names stick with the shell. They save with the storage block and travel with respawn anchors, so they survive a relog and are there for everyone on a server.
