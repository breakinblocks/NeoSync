# NeoSync 1.4.1

Respawn anchors can now be handed out as a single use. Add `true` on the end of the anchor set command and the anchor is spent the moment the player syncs into it, so it catches one death and then it is gone. Leave it off and the anchor keeps working the way it always has.

There is also a new ensure form of the command. It gives a player a single use anchor only when they have nothing left to sync into, and does nothing at all when they still have a shell standing. Pack makers can safely run it on a timer or on login to keep players from getting stranded with no way back.

The anchor list command now marks which anchors are single use, and every anchor command reports how many players or anchors it touched so scripts can check the result.
